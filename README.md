# Video Belajar App

Platform pembelajaran online berbasis video untuk meningkatkan skill dan pengetahuan.

# Video Belajar App Vercel

[link-vercel](https://video-belajar-app.vercel.app/)

## Tech

- React 19
- Vite
- Tailwind CSS
- React Router DOM
- localStorage untuk data user
- API-based untuk data courses

## Fitur Utama

- Katalog kelas pembelajaran dengan filter kategori
- Sistem autentikasi (Register & Login)
- Admin dashboard untuk CRUD kelas
- Responsive design untuk semua device
- Data user menggunakan localStorage
- Data courses menggunakan API-based

Aplikasi akan berjalan di `http://localhost:5173`
